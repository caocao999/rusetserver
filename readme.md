# rustserver

Cisco IOSのアクセス制御リスト（ACL）を学習・検証するための、Rust製の簡易HTTPサーバーです。Axumを使用し、固定HTMLページを返します。

**学習・検証用途のサンプルです。本番環境向けのWebサーバーではありません。**

## 必要な環境

- Rust / Cargo
- 通信確認に使うブラウザ、または `curl`
- ACLを検証する場合は、通信経路上に配置した検証用ルータなど

## 使い方

リポジトリを取得し、そのディレクトリで実行します。

```powershell
git clone https://github.com/caocao999/rusetserver.git
cd rusetserver
cargo run
```

引数を省略した場合、ポート **3000** で待ち受けます。別のポートを使う場合は、次のように指定します。

```powershell
cargo run -- 8080
```

ビルドした実行ファイルを直接使うこともできます。

```powershell
cargo build --release
.\target\release\rustserver.exe 8080
```

> `cargo run -- 8080` の `--` は、後続の `8080` をプログラム本体へ渡すための区切りです。指定できるのは有効なTCPポート番号です。

## アクセス方法

サーバー自身のPCからアクセスする場合：

```text
http://127.0.0.1:3000/
```

別のPCからアクセスする場合（IPアドレスとポートは例）：

```powershell
curl.exe -i http://192.168.2.10:8080/
```

サーバーは `0.0.0.0`（すべてのIPv4インターフェース）で待ち受けます。クライアントからは `0.0.0.0` ではなく、**サーバーPCの実際のIPアドレス**を指定してください。OSのファイアウォールやネットワークの設定によっては、別PCからアクセスできない場合があります。

## ACL実習での使い方

1. ACLを適用する前にHTTP通信が成功することを確認します。
2. Cisco IOSで検証対象のACLを設定・適用します。
3. 同じ送信元・宛先・TCPポートで再度アクセスし、結果を比較します。

異なるポートで試す場合は、各ポートごとに別のサーバープロセスを起動します。ACLの動作を判断する際は、**Windowsファイアウォールによる遮断**や、**通信がそもそも対象ルータを経由していない構成**と混同しないようにしてください。

## 固定HTMLについて

`static/index.html` は `include_str!` により**ビルド時に実行ファイルへ組み込まれます**。HTMLを編集したら再ビルドが必要です。ビルド後、実行時に `static/index.html` を配置する必要はありません。
